# ความชอบและข้อกำหนดของเจ้าของงาน

สรุปจากสิ่งที่เจ้าของงานพูดไว้ในเซสชันแรก (ต.ค. 2026) ใช้เป็นบรีฟตั้งต้นของคลิปใหม่ทุกคลิป

## เป้าหมาย

- ทำคลิปอธิบายวิทยาศาสตร์ลง **YouTube Shorts / TikTok** — แนวตั้ง 1080×1920
- สร้างด้วยโค้ดทั้งหมด (ภาพ เสียงพากย์ ดนตรี เอฟเฟกต์เสียง) โดยให้ Claude เป็นคนทำ

## เนื้อหา

| ข้อกำหนด | ที่มา |
|---|---|
| **วิทยาศาสตร์ต้องสมเหตุสมผล** ทุกภาพต้องถูกหลัก ไม่ใช่แค่สวย | "ตอนซูมอะตอมเข้าไป ทำไมเห็นแค่ออกซิเจน มันควรจะเห็นไฮโดรเจนอยู่ด้วยกันด้วย" |
| **เล่าให้น่าสนใจ** เปิดด้วยคำถามหรือปริศนา แล้วให้คำตอบมาจากระดับโมเลกุล | ขอให้เรียบเรียงใหม่ให้น่าสนใจ แล้วเลือกเรื่อง "ปริศนา 100 °C" |
| **สิ่งที่บทพูดถึงต้องเห็นชัดในภาพ** เช่น ถ้าบอกว่ากำลังให้ความร้อน ต้องเห็นไฟชัด | "มันดูไม่ชัดว่ากำลังให้ความร้อนเลย ไฟใต้เตามันดูไม่ออก" |

## เสียง

| ข้อกำหนด | รายละเอียด |
|---|---|
| เสียงพากย์ | อังกฤษ เสียงผู้ชาย Kokoro `am_michael` (speed 1.05) — ชอบเสียงนี้ที่สุด |
| ภาษาไทย | Kokoro ไม่รองรับไทย ถ้าจะพากย์ไทยต้องหา TTS ตัวอื่น |
| ดนตรี + เสียงประกอบ | ต้องมีดนตรีและเสียงประกอบเรื่อง (เช่น เสียงน้ำเดือด) |
| **เสียงพูดต้องฟังชัดเสมอ** | เคยมีปัญหาเสียงวี๊ดตอนโมเลกุลสั่นดังจนกลบเสียงพูด → ห้ามมีเสียงแหลม/เสียงสูง ใช้ ducking ลดดนตรีกับ SFX ลง ~9 dB ขณะพูด และให้ดนตรีอยู่ต่ำกว่าเสียงพูดราว 12–13 dB |
| ความดัง | ประมาณ −16 LUFS, peak ≤ −1 dBTP |

## เครื่องมือ

- ตอนนี้ใช้ **HyperFrames** เป็นหลักสำหรับ Shorts ("พัก blender ไว้ก่อน")
- ชอบงาน 3D จาก Blender มาก ("โห สวยมาก") อาจกลับมาใช้ทั้งคลิปหรือใช้คู่กับ HyperFrames ภายหลัง
- สนใจว่าคนอื่นใช้ Claude ทำวิดีโอกันอย่างไร และสนใจเรื่องการสร้างเสียงด้วยโค้ด/โมเดลในเครื่อง

## สไตล์ภาพที่ใช้อยู่ (คลิป 100 °C)

- อะตอม: O สีแดง `#E5484D`, H สีขาว `#F3F6F8` — แสดงเป็นโมเลกุล H₂O ครบเสมอ
- สีส้ม `#FF7A2F` ใช้กับ "ความร้อน" เท่านั้น
- ตัวเลขใช้ League Gothic, ซับไตเติลใช้ Inter 900 มีขอบเข้ม เน้นคำสำคัญด้วยสี
- คำต้องอยู่ในช่วง y 168–1330 และไม่ทับปุ่มด้านขวาของแอป

## การสื่อสาร

- คุยภาษาไทย สั้น ตรง เป็นตาราง/ข้อสั้น ๆ
- ถ้ามีคำอธิบายไม่สอดคล้องกัน เจ้าของงานจะจับได้ — อธิบายให้เป็นเหตุเป็นผล
