# วิทยาศาสตร์ของเรื่องน้ำเดือด

## ข้อเท็จจริงที่ตรวจแล้ว

| เรื่อง | ค่า | วิธีคิด |
|---|---|---|
| จำนวนโมเลกุลในน้ำ 250 mL | ≈ 8.4 × 10²⁴ | 250 g ÷ 18.015 g/mol × 6.022 × 10²³ |
| ปริมาตรไอน้ำเทียบน้ำ (100 °C, 1 atm) | ≈ 1,600 เท่า | 958.4 ÷ 0.598 kg/m³ ≈ 1,603 |
| ระยะห่างโมเลกุล | ~0.31 nm (ของเหลว), ~3.7 nm (ไอ) | รากที่สามของปริมาตรต่อโมเลกุล |
| พลังงานทำให้เดือดหมด vs. อุ่นจาก 20→100 °C | 2,257 vs 334 kJ/kg (≈ 6.7×) | ความร้อนแฝงของการกลายเป็นไอ |
| ความเร็วเฉลี่ยโมเลกุล | ∝ √T → 20→100 °C เร็วขึ้น ~13% | v_rms = √(3kT/m) |
| โครงสร้างโมเลกุล | O–H 0.96 Å, มุม H–O–H 104.5° | |
| พันธะไฮโดรเจน | ระยะ H···O ~1.7–2.0 Å | |

## สิ่งที่ต้องเลี่ยง (เคยผิดในเวอร์ชันแรก)

| ผิด | ถูก |
|---|---|
| ซูมแล้วเห็นอะตอม O ลอยเดี่ยว | น้ำเป็นโมเลกุล H₂O เสมอ ต้องเห็น H สองตัวติดอยู่กับ O |
| อะตอม/โมเลกุล "ร้อนจนเรืองแสง" | อุณหภูมิ = โมเลกุลเคลื่อนที่/สั่นเร็วขึ้น ไม่ได้เปลี่ยนสี |
| "พันธะแตก" แบบกำกวม | ที่ขาดคือ **พันธะไฮโดรเจนระหว่างโมเลกุล** ส่วนพันธะ O–H ในโมเลกุลไม่ขาด |
| เรียกควันขาวว่าไอน้ำ | ไอน้ำมองไม่เห็น ควันขาวคือหยดน้ำที่ควบแน่นกลับ |
| อุณหภูมิขึ้นต่อเนื่องตอนเดือด | ที่ 1 atm ค้างที่ 100 °C ความร้อนไปใช้ตัดพันธะไฮโดรเจนแทน |
