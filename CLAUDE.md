# x-sci-thing — instructions for Claude

Vertical (1080×1920) science explainers for YouTube Shorts / TikTok, made entirely in code.

Before planning or changing any video, read:
- `docs/PREFERENCES.md` — the owner's requirements (scientific accuracy, interesting story, voice always audible, what the narration says must be visible on screen)
- `docs/SCIENCE.md` — checked facts and mistakes to avoid
- `docs/TOOLS.md` — tool choices, the build pipeline and machine limits

Defaults:
- HyperFrames for Shorts; Blender only for special 3D shots
- English narration with Kokoro `am_michael` (speed 1.05) unless asked otherwise
- Before delivering, run `hyperframes check`, look at snapshots, check the science, and mix to about −16 LUFS with the voice clearly on top
- Reply to the owner in Thai, short and direct, using tables where they help
