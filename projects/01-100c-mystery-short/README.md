# The 100 °C mystery (HyperFrames short)

ไฟยังเปิดอยู่ ทำไมน้ำค้างที่ 100 °C — ซูมลงไปถึงโมเลกุล H₂O, ประจุ δ−/δ+, พันธะไฮโดรเจน,
ความร้อนทำให้สั่นเร็วขึ้น, ที่ 100 °C ความร้อนไปตัดพันธะไฮโดรเจนแทน, น้ำ 1 ถ้วย → ไอ ~1,600 ถ้วย

| ไฟล์ | หน้าที่ |
|---|---|
| `STORYLINES.md` | 3 เรื่องที่เสนอ (เลือก A) + ข้อเท็จจริง |
| `SPEC.md` | บรีฟผู้กำกับ: ความยาว สี ฟอนต์ สิ่งที่ห้ามทำ |
| `tools/voice.py` | บทพูด + สร้างเสียงด้วย Kokoro |
| `tools/layout.py` | วางบรรทัดบนไทม์ไลน์ → `timeline.json` |
| `tools/build.py` | สร้าง `compositions/*.html` และ `index.html` |
| `tools/mix.py` | มิกซ์เสียงพากย์ + ดนตรี + SFX + เสียงเดือด (ducking, −16 LUFS) |
| `lib/water2d.js` | จำลองน้ำ 2D: 82 โมเลกุล, 122 พันธะไฮโดรเจน, โมเลกุลที่หลุดออก |
| `lib/kitchen.js` | เตา หม้อ เปลวไฟ เทอร์โมมิเตอร์ กราฟการให้ความร้อน |

วิธีสร้างใหม่ดูใน `docs/TOOLS.md` ที่ root ของ repo
